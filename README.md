One Word for the Boss: **Reply-all**

One word for the boss: **Reply-all** — the boss as a behaviour, every message a reply-all. Funny on its own, true of a real habit, and fresh (only 10 copies in the field). The other candidates — 'ASAP' and 'Micromanager' — are kept in `vA/`, `vB/`, `vC/`; vA was chosen because it carries a whole character in one word and is the least copied.

## Run it

```sh
node main.ts
```

Requires Node 22.18 or later (the grader runs Node 26.13.1 per the kit).
The program writes exactly the entry above to `/output/entry.txt` — no
trailing newline, so the file holds exactly the entry — and prints exactly
that text to stdout. It uses no network, no randomness, no clock and no
environment input, so two runs produce byte-identical output.
